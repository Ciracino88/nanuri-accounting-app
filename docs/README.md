## 먼저 읽을 것

**이 앱이 하는 일은 찬양팀 일정 조율 하나입니다.** 멤버가 주일마다 자기 포지션에 "설 수 있음"을
토글로 표시하는 것. 2026-08-28 에 그 하나만 남기고 전부 걷어냈습니다 — 소모임·비용 청구·
관리자 화면은 삭제됐고, 회계는 관리자 iOS 앱으로 넘어갔습니다.

두 가지를 미리 알아두세요.

- **⚠ DB 를 혼자 쓰지 않습니다.** 관리자 iOS 앱(NanuriAdmin)과 **같은 Supabase 프로젝트**를
  공유합니다. 2026-08-13 에 그쪽 마이그레이션의 `drop schema public cascade` 가 이 앱의
  테이블을 전부 지웠고 데이터는 복구하지 못했습니다. 스키마를 건드리기 전에
  [status.md의 사고 기록](status.md#-2026-08-13-스키마-삭제-사고)을 꼭 보세요.
- **복구 마이그레이션이 아직 원격에 적용되지 않았습니다.**
  `20260828000000_restore_worship_schema.sql` 을 밀기 전까지 앱은 로그인 직후 프로필 설정
  화면에서 무한 루프입니다. 적용 방법은 [status.md](status.md#복구-마이그레이션-적용하기)에
  있습니다.

화면을 손대기 전에는 [design.md](design.md)를 보세요. 값마다 "원티드 확인값"인지 "우리 값"인지
구분해 뒀고, 그게 판단 근거입니다.

> 옛 문서나 커밋에서 카테고리 틴트(teal/pink/amber)·액센트 퍼플, "라이트 리디자인 3단계",
> 행사·갤러리·순서별 평가를 보더라도 **지금은 없는 개념**입니다.
